### 📊 Featured Project

#### 🧬 TCGA Genomic Survival Analysis & Predictive Modeling Pipeline
* **Repository:** [TCGA-Survival-Analysis-ML](https://github.com/the-tayelolu/TCGA-Survival-Analysis-ML)
* **Data Processing:** Integrated somatic mutation profiles with clinical endpoints across **996 TCGA patient records**.
* **Benchmark Results:** Built and validated a multi-model architecture. **Random Forest** outperformed traditional linear baselines, achieving an **AUC of 0.954** and **95.6% Classification Accuracy**.
* **Open Science & Artifacts:** Published reproducible workflow files (`.ows`), benchmark outputs (`.csv`), and publication-ready evaluation reports (`.pdf`).
